# Mason Agent brand package

The Mason Agent logo kit. Start with `brand-guidelines.pdf` or `BRAND-GUIDE.md`.

## Folders

- `svg/` - authoritative scalable logo artwork
- `png/` - transparent production renders at multiple sizes
- `favicon/` - browser, app, and touch icons plus web manifest
- `preview/` - overview, usage, avatar, and social-share assets
- `fonts/` - redistributable supporting typeface and license
- `tokens/` - machine-readable color values for design and development

The logo lettering is outlined custom artwork, so it does not depend on an installed font. The bundled font is for supporting brand communication.
